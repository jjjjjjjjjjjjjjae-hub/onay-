# ONAY Demo APK

APK GitHub Actions арқылы жиналады. Қосымша осы репозиторийдің түбіріндегі index.html бетін WebView ішінде көрсетеді және image.png файлын launcher белгішесі ретінде пайдаланады.

Бұл — ресми емес демонстрациялық қабық. Нақты ONAY қызметі, төлем немесе билет жарамдылығы расталмайды.

APK алу: GitHub → Actions → Build Android APK → соңғы сәтті run → Artifacts → onay-demo-debug-apk.
